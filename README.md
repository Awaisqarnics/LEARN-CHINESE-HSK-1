**HSK 1 Chinese Learning Website**

An interactive and beginner-friendly website designed to help learners practice HSK 1 Chinese vocabulary, recognize Chinese characters, and improve their writing skills.

 🌟 Features

- 📚 **HSK 1 Vocabulary Library** — Browse and study Chinese vocabulary.
- 🔍 **Vocabulary Search** — Find Chinese words quickly.
- 🧠 **Word Practice** — Practice remembering Chinese characters and vocabulary.
- ✍️ **Chinese Writing Canvas** — Practice writing Chinese characters.
- ✅ **Stroke Check Mode** — Check your character-writing practice.
- 📝 **Quizzes** — Test your Chinese vocabulary knowledge.
- 📊 **Progress Dashboard** — Track your learning progress.
- 💾 **Progress Saving** — Save learning progress in your browser.
- 📤 **Export Progress** — Export supported learning data in CSV or JSON format.
- 📱 **Responsive Design** — Works on desktop, tablet, and mobile devices.
- 🔊 **Chinese Pronunciation** — Listen to pronunciation where supported by your browser and device.

 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

 💻 How to Run the Project

1. Download or clone this repository.
2. Extract the project files if you downloaded a ZIP file.
3. Open the project folder.
4. Open `index.html` in your web browser.

 💾 Learning Progress

Learning progress is stored in the browser's Local Storage.

- Progress can remain saved when using the same browser.
- Progress does not automatically synchronize between devices.
- Clearing browser data may remove saved progress.

 🎯 Project Goal

The goal of this project is to make learning Chinese easier, more engaging, and more interactive through vocabulary practice, character writing, quizzes, and progress tracking.
